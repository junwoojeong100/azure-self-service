# 실습 가이드 안내

가이드를 역할별로 분리했습니다.

- **[IT 부서 가이드](IT_DEPARTMENT_GUIDE.md):** 담당자 전용 Resource Group 생성, RG 범위 `Owner` 위임, 비용·정책·오프보딩 관리
- **[현업 담당자 가이드](BUSINESS_USER_GUIDE.md):** GitHub Copilot 또는 Claude Code로 FastAPI 앱을 개발하고 GitHub Actions와 Azure Container Apps에 자율 배포

실습은 IT 부서가 먼저 전용 RG와 RG 범위 Owner 권한을 제공한 뒤, 현업 담당자가 자신의 가이드를 따라 진행합니다.
